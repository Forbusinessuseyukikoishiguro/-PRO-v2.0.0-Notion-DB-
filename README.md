## はじめに

こんにちは、うさうさ先生です🐰

研修のサブ講師をやっていると、こんな瞬間がありませんか？

> 受講生さんから「P30のここ、解答がよく分からなくて…」と相談を受ける
> → メイン講師に確認しなきゃ
> → え、前回どういうフォーマットで送ったっけ…？
> → 過去のチャットを遡る
> → 日時を書き忘れて送り直す😇

演習中は机間巡視・質問対応・時間管理が同時進行。**連絡文を考える時間が一番もったいない**のです。このツールは、その「もったいない」をなくすために生まれました。

---

## 🤔 WHY：なぜ作ったの？

理由は3つあります。

### 理由①：フォーマットが揺れると、メイン講師の負担になる

確認依頼の文面が毎回バラバラだと、受け取る側は「いつ？どのクラス？どのページ？」を読み解くところから始めることになります。**型が揃っている＝相手が脳のリソースを使わずに済む**。これは報連相の基本ですね。

### 理由②：「送って終わり」だと、質問が記録に残らない

メイン講師に送った相談は、研修全体のナレッジの卵です🥚 でも手書き連絡だけだと、後から「あの質問、結局どう回答したっけ？」が追えません。**送ると同時にNotionの質問ダッシュボードDBへ自動起票**されれば、回答ステータス管理もFAQ昇格もできます。

### 理由③：演習中の操作は「速く・確実に」が正義

手が空くのは数十秒。だから入力→生成→コピーが最短動線で完結し、Ctrl+Enterの片手操作にも対応しました。

---

## 📦 WHAT：何ができるの？

ひとことで言うと——

> **入力フォームに相談内容を入れると、メイン講師向けの定型文を自動生成し、ワンクリックでNotionにも起票できる単一HTMLツール**です🍜

### 生成される定型文（こんな形）

```
2026年6月4日 10:30
グループ：Aグループ
タイトル：セキュリティ応用研修 演習2-1
演習の進め方について、〇〇さんよりご相談をいただきました。
P30の「必要になるサーバの書き出し」で判断に迷うとのこと
お手数ですが、当該箇所の正しい解答・内容をご教示いただけますでしょうか。
```

複数件は `ーーー` 区切りで自動連結。休憩時間にまとめて1通で送れます。

### 主な機能

| 機能 | 説明 |
|------|------|
| 定型文生成 | 日時・グループ・タイトル・相談者・該当ページ・内容から自動組み立て |
| 複数件まとめ | `ーーー` 区切りで連結し、一括コピー |
| Notion自動起票 | ❓質問ダッシュボードDBへ登録（回答者=メイン講師／ステータス=未着手） |
| 個別操作 | 1件単位のコピー📋・編集✏️・削除✕ |
| 必須チェック | 未入力項目を赤枠で警告（送信事故防止） |
| ショートカット | Ctrl+Enter（Mac: ⌘+Enter）で追加 |
| 起票サブ講師欄 | 可変（既定: 石黒） |

## 🚀 HOW：どう使うの？

### ステップ1：開く

`うさうさ_質問エスカレ文ジェネレーターPRO_v2.0.0_20260604.html` をブラウザで開きます。インストール不要、これ1ファイルで完結です。

### ステップ2：入力する

左のフォームに相談内容を入力。日付・時刻は開いた時点の値が自動で入っています。`*` 付きは必須項目です（グループ／タイトル／相談者／内容）。

### ステップ3：追加する

「➕ この相談を追加する」（または Ctrl+Enter）。右側に定型文が生成されます。複数相談があれば、相談者と内容だけ書き換えてどんどん追加。

### ステップ4：送る＆記録する

- **📋 全文コピー** → Teamsやメールに貼り付けてメイン講師へ
- **💾 Notionへ一括起票** → 質問ダッシュボードDBに自動登録

具体的には、Notion側にはこう入ります：

> 質問要約「【セキュリティ応用研修 演習2-1】P30 演習の進め方相談（〇〇さん）」／カテゴリ・緊急度はフォームの選択値／発生日時は入力した日時

正式には、Notion MCP経由で `notion-create-pages` を呼び出し、データソース `a2701198-...` 配下にページを作成しています（このあたりはツールが勝手にやってくれるので意識不要です）。

## ⚠️ 使う前に知っておいてほしいこと

1. **Notion起票はClaude.aiのアーティファクト内で開いた場合のみ動作**します。ローカル保存版では文面生成＋コピー専用です（オフラインでも研修現場で使えるよう、生成機能はAPI不要設計）。
2. **入力データはページを閉じると消えます**。これは個人情報を端末に残さないための意図的な設計です。コピー or 起票をお忘れなく。
3. 受講生名の扱いは受講生カルテ運用ルールに準拠してください（姓のみ推奨）。作成物に同僚・関係者の個人名は記載しない方針です（役職名で代替）。

## 🧪 品質について（試験でるところ…ではなく、テストしたところ）

商用レベルの7フェーズ基準のうち、本ツールでは以下を実施し**全件パス**しています。

- 単体テスト 27項目（日付整形／XSSエスケープ／定型文6行構成／ーーー連結／NotionDBスキーマ整合／境界値500字・年末日時）
- 静的検査（JS構文・関数/ID参照整合・タグ開閉・禁止API不使用・刻印確認）

v2.0.0の最重要修正は、v1.0にあった**ユーザー入力をそのまま描画するXSS脆弱性の解消**です。「動く」と「安全に動く」は別物、というのは研修でもお伝えしている通りですね🐰
